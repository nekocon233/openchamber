# Skills-Katalog

Im Skills-Katalog kannst du Skills installieren, die andere veröffentlicht haben, statt selbst welche zu schreiben. Du öffnest ihn unter **Einstellungen → Skills → Katalog**.

Zum Schreiben eigener Skills siehe [Skills](/skills/).

## Einen Skill installieren

1. Öffne den Katalog.
2. Durchsuche die eingebauten Quellen — wie das Anthropic-Skills-Repo — oder nutze die Suche.
3. Wähle einen Skill aus und installiere ihn.
4. Entscheide, wo er installiert werden soll: für alles, was du tust, oder nur für das aktuelle Projekt.

Wenn bereits ein Skill mit demselben Namen existiert, fragt OpenChamber, was geschehen soll — überspringen, überschreiben oder für jeden Skill einzeln entscheiden.

## Eigene Quelle hinzufügen

Du kannst jedes Git-Repository als Quelle hinzufügen — entweder mit seinem `owner/repo`-Namen oder mit einer vollständigen Git-URL. Private Repositories brauchen Zugriff auf deinem Rechner (einen SSH-Schlüssel oder gespeicherte Anmeldedaten); wenn sich eine Quelle nicht authentifizieren kann, weist der Katalog darauf hin, statt still zu scheitern. Für einen anderen Branch oder Tag als den Standard hängst du ihn mit `#` an: `owner/repo#develop` oder `https://github.com/owner/repo.git#v1.0.0`.

## Installierte Skills aktualisieren

Ein aus einem Katalog installierter Skill bleibt auf der Version, die er bei der Installation hatte. **Update installed** auf der Katalogseite lädt jeden installierten Katalog-Skill erneut aus seiner Quelle und ersetzt die lokale Kopie. Lokale Änderungen an diesen Skills gehen verloren, selbst geschriebene Skills bleiben unberührt.

Der Dialog listet vorher auf, was ersetzt wird, und meldet danach jeden Skill, der nicht ersetzt werden konnte, mit dem Grund.
