# Skills

Ein Skill ist ein wiederverwendbarer Satz von Anweisungen, den ein Agent bei Bedarf laden kann — zum Beispiel „wie wir Commit-Nachrichten schreiben“ oder „unsere API-Konventionen“. Du verwaltest sie unter **Einstellungen → Skills**.

Wenn du fertige Skills installieren statt eigene schreiben möchtest, siehe [Skills-Katalog](/skills-catalog/).

## Einen Skill erstellen

1. Öffne **Einstellungen → Skills**.
2. Erstelle einen Skill und gib ihm einen Namen und eine kurze Beschreibung. Die Beschreibung ist die Grundlage dafür, wann der Agent den Skill anwendet. Sei daher konkret.
3. Schreibe die Anweisungen. Füge unterstützende Dateien hinzu, falls der Skill sie braucht.
4. Wähle den Speicherort:
   - **persönlich** — in jedem Projekt verfügbar
   - **projektbezogen** — nur im aktuellen Projekt verfügbar

## Einen Skill im Chat verwenden

Gib irgendwo in einer Nachricht `$` ein, auch ganz am Anfang, um die Skill-Auswahl zu öffnen, und wähle dann einen Skill aus. Der Agent lädt für die Antwort die Anweisungen dieses Skills.

Ein `/` ganz am Anfang der Nachricht öffnet [Befehle](/commands-snippets/); Skills sind dort nicht dabei.

## Benutzerskills aus Agent-Plugins synchronisieren

Die Skills in `~/.agents/skills` können Kopien von Skills sein, die mit den Plugins Claude Code und Codex ausgeliefert werden. Die Aktualisieren-Schaltfläche neben der Skill-Anzahl unter **Einstellungen → Skills** listet diese Kopien und ersetzt sie durch die Version aus dem installierten Plugin.

Der Dialog zeigt vor jeder Änderung, was ersetzt und was unangetastet bleibt. Symlinks und Skills ohne Plugin-Quelle werden übersprungen und genannt. Der ganze Skill-Ordner wird ersetzt, lokale Änderungen an diesen Kopien gehen verloren. Skills, die du selbst geschrieben hast, bleiben unangetastet.
