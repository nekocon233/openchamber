# Catálogo de skills

El catálogo de skills te permite instalar skills que otras personas han publicado en lugar de escribir las tuyas. Ábrelo en **Settings → Skills → Catalog**.

Para escribir tus propias skills, consulta [Skills](/es/skills/).

## Instala una skill

1. Abre el catálogo.
2. Explora las fuentes integradas —como el repositorio de skills de Anthropic— o busca.
3. Elige una skill e instálala.
4. Elige dónde instalarla: para todo lo que hagas, o solo en el proyecto actual.

Si ya existe una skill con el mismo nombre, OpenChamber pregunta qué hacer: omitirla, sobrescribirla o decidir skill por skill.

## Añade tu propia fuente

Puedes añadir cualquier repositorio de Git como fuente usando su nombre `owner/repo` o una URL de Git completa. Los repositorios privados necesitan tener el acceso configurado en tu máquina (una clave SSH o credenciales guardadas); si una fuente no puede autenticarse, el catálogo lo indica en lugar de fallar en silencio. Para usar una rama o etiqueta distinta de la predeterminada, añádela tras `#`: `owner/repo#develop` o `https://github.com/owner/repo.git#v1.0.0`.

## Actualizar los skills instalados

Un skill instalado desde un catálogo se queda en la versión con la que lo instalaste. **Update installed** en la página del catálogo descarga de nuevo cada skill de catálogo instalado desde su fuente y sustituye la copia local. Los cambios locales en esos skills se pierden, y los skills que escribiste tú no se tocan.

El diálogo muestra antes qué se va a sustituir y después informa de cada skill que no se pudo sustituir, con el motivo.
