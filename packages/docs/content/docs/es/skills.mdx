# Skills

Una skill es un conjunto reutilizable de instrucciones que un agente puede incorporar cuando es relevante; por ejemplo, "cómo escribimos los mensajes de commit" o "nuestras convenciones de API". Las gestionas en **Settings → Skills**.

Para instalar skills ya hechas en lugar de escribir las tuyas, consulta [Catálogo de skills](/es/skills-catalog/).

## Crea una skill

1. Abre **Settings → Skills**.
2. Crea una skill y dale un nombre y una descripción breve. La descripción es lo que el agente usa para decidir cuándo aplica la skill, así que hazla específica.
3. Escribe las instrucciones. Añade archivos de apoyo si la skill los necesita.
4. Elige dónde vive:
   - **personal** — disponible en todos los proyectos
   - **proyecto** — disponible solo en el proyecto actual

## Usa una skill en el chat

Escribe `$` en cualquier parte de un mensaje, también al principio, para abrir el selector de skills y elige una. El agente carga las instrucciones de esa skill para la respuesta.

Una `/` al principio del mensaje abre los [comandos](/es/commands-snippets/), que no incluyen skills.

## Sincronizar skills de usuario desde plugins de agentes

Los skills de `~/.agents/skills` pueden ser copias de skills que vienen con los plugins Claude Code y Codex. El botón de actualización junto al número de skills en **Settings → Skills** lista esas copias y las reemplaza por la versión del plugin instalado.

El diálogo muestra qué se reemplazará y qué se dejará intacto antes de cambiar nada. Los enlaces simbólicos y los skills sin origen de plugin se omiten y se nombran. Se reemplaza la carpeta completa del skill, así que los cambios locales en esas copias se pierden. Los skills que escribiste tú nunca se tocan.
