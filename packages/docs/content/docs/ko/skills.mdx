# 스킬

스킬은 에이전트가 관련이 있을 때 불러올 수 있는 재사용 가능한 지침 모음입니다. 예를 들어 "커밋 메시지를 작성하는 방식"이나 "우리의 API 규칙" 같은 것입니다. **Settings → Skills**에서 관리합니다.

직접 작성하는 대신 이미 만들어진 스킬을 설치하려면 [Skills Catalog](/ko/skills-catalog/)를 참고하세요.

## 스킬 만들기

1. **Settings → Skills**를 엽니다.
2. 스킬을 만들고 이름과 짧은 설명을 지정합니다. 에이전트는 이 설명을 보고 스킬이 적용될 시점을 판단하므로 구체적으로 작성하세요.
3. 지침을 작성합니다. 스킬에 필요하다면 보조 파일을 추가합니다.
4. 저장 위치를 선택합니다.
   - **personal** — 모든 프로젝트에서 사용 가능
   - **project** — 현재 프로젝트에서만 사용 가능

## 채팅에서 스킬 사용하기

메시지 맨 앞을 포함해 어디에서든 `$`를 입력하면 스킬 선택기가 나타나며, 그중 하나를 선택합니다. 에이전트가 해당 스킬의 지침을 응답에 불러옵니다.

메시지 맨 앞의 `/`는 [명령](/ko/commands-snippets/)을 엽니다. 여기에는 스킬이 포함되지 않습니다.

## 에이전트 플러그인에서 사용자 skill 동기화

`~/.agents/skills`의 skill은 Claude Code, Codex 플러그인에 포함된 skill의 복사본일 수 있습니다. **Settings → Skills**의 skill 수 옆에 있는 새로 고침 버튼이 그 복사본을 나열하고 설치된 플러그인의 버전으로 바꿉니다.

변경 전에 대화상자가 무엇을 바꾸고 무엇을 그대로 둘지 보여 줍니다. 심볼릭 링크와 플러그인 출처가 없는 skill은 건너뛰고 이름을 표시합니다. skill 폴더가 통째로 바뀌므로 그 복사본에 적용한 로컬 수정은 사라집니다. 직접 작성한 skill은 건드리지 않습니다.

## 관련 항목

- [Skills Catalog](/ko/skills-catalog/) — 다른 사람이 게시한 스킬을 설치하세요
- [Commands & Snippets](/ko/commands-snippets/) — 채팅에서 텍스트를 재사용하는 다른 방법
