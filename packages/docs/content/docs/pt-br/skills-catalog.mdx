# Catálogo de Skills

O Catálogo de Skills permite instalar skills que outras pessoas publicaram em vez de escrever as suas. Abra-o em **Settings → Skills → Catalog**.

Para escrever suas próprias skills, veja [Skills](/pt-br/skills/).

## Instalar uma skill

1. Abra o catálogo.
2. Navegue pelas fontes integradas — como o repositório de skills da Anthropic — ou pesquise.
3. Escolha uma skill e instale-a.
4. Escolha onde instalá-la: para tudo o que você faz, ou apenas no projeto atual.

Se já existir uma skill com o mesmo nome, o OpenChamber pergunta o que fazer — pular, sobrescrever ou decidir por skill.

## Adicionar sua própria fonte

Você pode adicionar qualquer repositório Git como fonte usando seu nome `owner/repo` ou uma URL Git completa. Repositórios privados precisam de acesso configurado na sua máquina (uma chave SSH ou credenciais salvas); se uma fonte não conseguir autenticar, o catálogo avisa em vez de falhar silenciosamente. Para usar um branch ou tag diferente do padrão, adicione depois de `#`: `owner/repo#develop` ou `https://github.com/owner/repo.git#v1.0.0`.

## Atualizar os skills instalados

Um skill instalado de um catálogo fica na versão com que foi instalado. **Update installed** na página do catálogo baixa de novo cada skill de catálogo instalado a partir da sua fonte e substitui a cópia local. Alterações locais nesses skills são perdidas, e skills que você escreveu não são alterados.

A caixa de diálogo lista antes o que será substituído e depois informa cada skill que não pôde ser substituído, com o motivo.
