# Skills

Uma skill é um conjunto reutilizável de instruções que um agente pode incorporar quando for relevante — por exemplo, "como escrevemos mensagens de commit" ou "nossas convenções de API". Você as gerencia em **Settings → Skills**.

Para instalar skills prontas em vez de escrever as suas, veja o [Catálogo de Skills](/pt-br/skills-catalog/).

## Criar uma skill

1. Abra **Settings → Skills**.
2. Crie uma skill e dê a ela um nome e uma descrição curta. A descrição é como o agente decide quando a skill se aplica, então seja específico.
3. Escreva as instruções. Adicione arquivos de apoio se a skill precisar deles.
4. Escolha onde ela fica:
   - **personal** — disponível em todos os projetos
   - **project** — disponível apenas no projeto atual

## Usar uma skill no chat

Digite `$` em qualquer ponto de uma mensagem, inclusive no início, para abrir o seletor de skills e escolha uma. O agente carrega as instruções daquela skill para a resposta.

Um `/` logo no início da mensagem abre os [comandos](/pt-br/commands-snippets/), que não incluem skills.

## Sincronizar skills de usuário a partir de plugins de agentes

Os skills em `~/.agents/skills` podem ser cópias de skills que vêm com os plugins Claude Code e Codex. O botão de atualização ao lado da contagem de skills em **Settings → Skills** lista essas cópias e as substitui pela versão do plugin instalado.

A caixa de diálogo mostra o que será substituído e o que ficará intacto antes de qualquer alteração. Links simbólicos e skills sem origem em plugin são ignorados e nomeados. A pasta do skill é substituída por inteiro, então alterações locais nessas cópias são perdidas. Skills escritos por você nunca são tocados.
