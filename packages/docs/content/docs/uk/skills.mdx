# Навички

Навичка — це багаторазовий набір інструкцій, який агент може підтягнути, коли він доречний, — наприклад, «як ми пишемо повідомлення комітів» або «наші конвенції API». Керуйте ними в **Settings → Skills**.

Щоб установити готові навички замість писати власні, див. [Каталог навичок](/uk/skills-catalog/).

## Створення навички

1. Відкрийте **Settings → Skills**.
2. Створіть навичку й дайте їй назву та короткий опис. За описом агент вирішує, коли навичка застосовна, тож робіть його конкретним.
3. Напишіть інструкції. Додайте допоміжні файли, якщо навичка їх потребує.
4. Виберіть, де вона зберігається:
   - **personal** — доступна в кожному проєкті
   - **project** — доступна лише в поточному проєкті

## Використання навички в чаті

Введіть `$` будь-де в повідомленні, зокрема на початку, щоб викликати перемикач навичок, потім оберіть одну. Агент завантажить інструкції цієї навички для відповіді.

`/` на самому початку повідомлення відкриває [команди](/uk/commands-snippets/), навичок серед них немає.

## Синхронізація навичок користувача з плагінів агентів

Навички в `~/.agents/skills` можуть бути копіями навичок, що постачаються з плагінами Claude Code і Codex. Кнопка оновлення поруч із кількістю навичок у **Settings → Skills** показує ці копії та замінює їх версією з установленого плагіна.

Перед будь-якою зміною діалог показує, що буде замінено, а що залишиться недоторканим. Символічні посилання й навички без джерела в плагіні пропускаються, їхні назви показуються. Каталог навички замінюється повністю, тому локальні зміни в цих копіях втрачаються. Навички, які ви написали самі, не змінюються.
